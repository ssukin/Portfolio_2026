ⓘHow these map to your test plan
INDEPENDENT VARIABLE
Two things differ, and only two: the cover (splash gate vs. scroll hero with work visible) and the case-study structure (tabbed Problem/Process/Result vs. one linear narrative). Nav, copy, metrics, and the skim toggle are held constant so Task 1 and Task 2/3 results are attributable.
WHAT EACH TASK TOUCHES
T1 role & relevance → cover. T2 problem & contribution → case study opening + role strip. T3 outcome evidence → Result tab vs. section 04. T4 second project → end-of-study next-project button + nav. T5 background → About, which links back to project evidence in 1b. T6 decision is moderator-captured, per your call.
ASSUMPTIONS I MADE
Project content is invented placeholder — swap in your real work before testing. Third project is drawn as an empty slot so the "at least 3 projects" success criterion is visible without faking content. Greyscale only, sketch font, X-boxes for imagery: nothing here should read as a visual-design decision to a participant.
